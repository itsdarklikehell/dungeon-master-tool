# Dungeon Master Tool

A portable, offline-first DM tool. Build worlds, run sessions, play together — all in one app.

## Features

- **World Building** - Create and manage your campaign world
- **Session Management** - Plan and run sessions
- **Combat Tracker** - Track initiative, HP, and conditions
- **NPC Management** - Create and manage NPCs
- **Item Database** - Track items and loot
- **Offline-First** - Works without internet connection

## Tech Stack

- Flutter 3.41+
- Dart
- Supabase (optional cloud sync)

## Platforms

- Android
- iOS
- Windows
- Linux
- macOS

## Installation

### From Source

```bash
git clone https://github.com/itsdarklikehell/dungeon-master-tool.git
cd dungeon-master-tool
flutter pub get
flutter run
```

### Pre-built Binaries

Download from the [releases page](https://github.com/itsdarklikehell/dungeon-master-tool/releases).

## Development

```bash
# Run tests
flutter test

# Build for specific platform
flutter build apk
flutter build ios
flutter build windows
flutter build linux
flutter build macos
```
